   배경이 투명하지 않아도 됩니다 — 둥근 메달 바깥은 제가 잘라 냅니다.
4. 받으면 제단 홈 · 모험 지도 배지 · 유산 선택 창 · 결산 화면의 이모지를 모두 이 그림으로 바꿉니다.
